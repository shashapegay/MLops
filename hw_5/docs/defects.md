# Разбор пяти дефектов

Этот файл генерируется командой `make train` после обоих полных прогонов.
Генератор `src/report.py` подставляет сюда фактические значения из
`metrics/train_all_layers.json` и `metrics/train_freeze14.json`.

После `make train` этот файл содержит отдельный раздел по каждому дефекту:
validation loss, завышенный learning rate, `freeze14`, переносимость
адаптера и воспроизводимость. В каждом разделе указано, в чём был дефект,
как он проявлялся, как исправлен и каким числом подтверждён.

Запускайте:

```bash
make train
make compare
make check
```

После обучения не заменяйте числа из отчёта эталонными значениями из
методички: в отчёте должны остаться результаты именно вашего датасета.
